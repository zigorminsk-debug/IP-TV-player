# 08 — Паритет функциональности с Televizo

Обзор Televizo (по открытым материалам, версия ~1.9.x) и что реализовано в
IP-TV Player на момент v1.0.0.

| Функция Televizo | Статус | Комментарий |
|---|---|---|
| Плейлисты M3U (URL, неограниченно) | ✅ | Плюс редактирование, порядок, автообновление по расписанию |
| Xtream Codes API (live/VOD/series) | ✅ | Полный набор: категории, стримы, инфо фильмов/сериалов, эпизоды |
| EPG XMLTV (неограниченно) | ✅ | Окно −48ч…+8д, gzip, авто-источник для Xtream (`xmltv.php`) |
| EPG «сейчас/далее» в списке | ✅ | Список каналов + плеер |
| Телепрограмма (гид) | ✅ | 7 дней, сетка, «сейчас»-линия, тап по передаче |
| Catch-up / архивы | ✅ | Шаблоны `catchup-source`, режимы default/append/flussonic/shift, Xtream `tv_archive`, «с начала передачи», −30/−60/−120 мин |
| Сортировка и поиск | ✅ | По имени/порядку; поиск по каналам и передачам |
| Избранное | ✅ | Переживает обновление плейлистов |
| Родительский контроль (PIN) | ✅ | PIN + блокировка/скрытие категорий и каналов, сессия разблокировки 10 мин |
| Выбор аудиодорожки | ✅ | Диалог треков + предпочитаемый язык |
| Выбор субтитров | ✅ | Вкл/выкл/выбор дорожки |
| Выбор видео-качества | ✅ | Для адаптивных стримов (HLS/DASH) |
| Chromecast | ✅ (базово) | CastPlayer + default receiver; без GMS отключается |
| Фоновое воспроизведение | ✅ | MediaSessionService + медиа-уведомление |
| Картина-в-картине | ✅ | Кнопка в плеере (Android 8+) |
| Таймер сна | ✅ | 15–120 мин |
| Внешний плеер | ✅ | По кнопке (для UDP-multicast и экзотических протоколов) |
| Автообновление плейлистов | ✅ | WorkManager, 6/12/24 ч |
| Возобновление VOD/сериалов | ✅ | Прогресс по позициям |
| Android TV / TV-боксы | ✅ | Leanback-лаунчер, D-pad: зеппинг, seek, оверлеи |
| Резервное копирование настроек | ✅ | Экспорт/импорт JSON (плейлисты + EPG) |
| Самообновление приложения | ✅+ | У Televizo — через сторы; здесь — GitHub Releases с верификацией SHA-256 |
| Номер сборки у каждой версии | ✅+ | `versionCode` = номер запуска CI, виден в «О приложении» |
| Stalker Portal | ❌ | В roadmap ([07-CONTINUATION.md](07-CONTINUATION.md)) |
| Мультиэкран (несколько потоков) | ❌ | В roadmap |
| Автоопределение частоты кадров | ❌ | В roadmap |

«✅+» — функциональность шире, чем в бесплатной версии Televizo.
