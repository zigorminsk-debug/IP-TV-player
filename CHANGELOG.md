# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

**Схема версий:** `МАЖОР.МИНОР.<НОМЕР РЕЛИЗА>` — patch-компонента равна порядковому
номеру релиза, поэтому каждому GitHub Release соответствует ровно одна версия
(релиз #3 → `1.0.3`). Номер сборки (`versionCode`) присваивает CI = `run_number`.
Подробности — в [docs/04-RELEASE.md](docs/04-RELEASE.md).

## [1.0.2] — релиз #2

### Changed
- **Версионирование приведено в соответствие с релизами**: единый источник
  версии — `version.properties`, `versionName = мажор.минор.<номер релиза>`,
  номер релиза вычисляет `scripts/version.sh` по опубликованным тегам `vX.Y.Z`.
- Релизы из `main` публикуются с нормальными тегами `vX.Y.N` и заголовком
  «vX.Y.N — релиз #N (сборка M)» вместо прежних `auto-v1.0.0-dev-buildNN`.
- В приложении («Настройки → Обновления/О приложении») и в диалогах
  самообновления показывается `версия (релиз N · сборка M)`.
- `app-update.json` получил поле `releaseNumber`.
- `SHA256SUMS.txt` больше не содержит самого себя.
- Дайджест ошибок CI на ветке `ci/logs` содержит только файлы `ci-logs/`
  (раньше туда force-push'илась вся копия репозитория).

### Added
- `scripts/version.sh` — вычисление версии/номера релиза (режимы
  `next|tag|manual|dev`), используется CI и локально.
- `scripts/record_release.py` — CI записывает каждый выпущенный релиз в таблицу
  «История релизов» и в `LAST_RELEASE` после публикации.
- Gradle-задача `./gradlew -q :app:printVersion` — показывает версию, номер
  релиза и номер сборки.
- `workflow_dispatch` получил флаг «Опубликовать GitHub Release».

### Fixed
- Сборки веток больше не маскируются под релизную версию: они помечаются
  суффиксом `-dev` (`1.0.3-dev`) и не публикуются.
- `.gitignore` дополнен артефактами CI (`dist/`, `ci-logs/`, `*.log`, `.kotlin/`).

## [1.0.0] — релиз #1 — 2026-10-04

Первый публичный релиз.

### Added
- Плейлисты: неограниченное количество M3U и Xtream Codes (live/VOD/сериалы),
  редактирование, сортировка, автообновление по расписанию (6/12/24 ч).
- EPG: XMLTV-источники (в т.ч. gzip), телепрограмма на 7 дней с «сейчас»-линией,
  «сейчас/далее» в списке и плеере, EPG Xtream по запросу с кэшированием.
- Плеер (Media3/ExoPlayer): HLS/DASH/TS/RTMP/UDP, выбор видео/аудио/субтитров,
  аспект (вписать/растянуть/обрезать), зеппинг, список каналов, PiP,
  таймер сна, фоновое воспроизведение с медиа-уведомлением.
- Catch-up: шаблоны `catchup-source`, режимы default/append/flussonic/shift,
  Xtream `tv_archive`, просмотр «с начала передачи» и «−N минут».
- Избранное, поиск по каналам и передачам, сортировка, фильтр по категориям.
- Родительский контроль: PIN (PBKDF2), блокировка/скрытие категорий и каналов.
- Возобновление просмотра VOD и эпизодов сериалов.
- Chromecast (базово), внешний плеер, копирование ссылки.
- Android TV: leanback-лаунчер, баннер, D-pad управление в плеере.
- Экспорт/импорт настроек (JSON).
- Самообновление приложения из GitHub Releases: проверка `app-update.json`,
  скачивание с прогрессом, верификация SHA-256, установка поверх.
- CI/CD: автосборка на каждый push (тесты, APK debug/release, AAB), релизы по
  тегам `vX.Y.Z`, автоматический номер сборки = run_number, постоянный ключ
  подписи, `app-update.json` + `SHA256SUMS` в релизах.
- Документация: архитектура, сборка, CI/CD, релизы, самообновление, ключи,
  гайд для продолжения работы.
- Локализация: русский и английский.
- Юнит-тесты парсеров M3U/XMLTV, catch-up и Xtream URL-шаблонов.
