# Release signing key

`release-signing.p12` — постоянный ключ подписи release-сборок (PKCS#12,
RSA-4096, сертификат до 2126 г.). `keystore.properties` — параметры для Gradle.

Ключ намеренно находится в репозитории, чтобы:
- CI всегда подписывал сборки одним ключом → обновления ставятся поверх;
- любой продолжатель проекта мог собирать совместимые обновления.

⚠️ Прочитайте [docs/06-SIGNING-KEYS.md](../docs/06-SIGNING-KEYS.md):
- сделайте личный бэкап `.p12` и пароля;
- риски публичного ключа и как перевести подписание на GitHub-секреты;
- потеря ключа = принудительная переустановка у всех пользователей.

Для генерации нового ключа: `scripts/generate_keystore.sh`.
